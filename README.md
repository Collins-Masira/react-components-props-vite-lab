# 📝 Personal Blog (React Components & Props Lab)

## 📌 Project Description

This project is a simple **personal blog website** built using React.
It demonstrates core React concepts such as **components, props, and JSX**.

The application displays:

* A blog header
* An about section
* A list of blog articles

---

## 🚀 Features

* Component-based architecture
* Props used to pass data between components
* Dynamic rendering of articles using `.map()`
* Clean and simple UI styling
* Interactive "Read More" toggle for articles

## ⚙️ Installation & Setup

1. Clone the repository:

```
git clone <your-repo-link>
```

2. Navigate into the project:

```
cd react-components-props-vite-lab
```

3. Install dependencies:

```
npm install
```

4. Run the development server:

```
npm run dev
```

5. Open in browser:

```
http://localhost:5173/
```
